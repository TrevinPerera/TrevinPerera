## `03` — FEATURED ENGINEERING PROJECTS

### 01. AgroSnap — Modular Smart Agriculture Platform

**Domain:** Embedded Systems · Precision Agriculture · Modular Electronics

Developing a modular agricultural sensing platform designed around an ESP32-S3 base controller and interchangeable sensor modules.

**Key engineering features**

- Modular sensor architecture with magnetic alignment and pogo-pin connections.
- Environmental and soil-monitoring capabilities.
- Exploration of SPI-based communication between the base controller and intelligent modules.
- Hardware design focused on modularity, power efficiency, and extensibility.

**Technology stack:** ESP32-S3 · Embedded C/C++ · SPI · Sensor Interfaces

### 02. Live Weather Monitoring System

**Domain:** Embedded Systems · Environmental Monitoring · Data Visualization

An IoT-enabled environmental monitoring project that collects sensor measurements and displays them through a web dashboard.

**Key engineering features**

- ESP32-based sensor data acquisition.
- BME280 environmental sensing.
- Rain detection and UV sensing.
- SSD1306 OLED display integration.
- Firebase Realtime Database connectivity.
- Web dashboard with live measurements, status indicators, and historical charts.

**Technology stack:** ESP32 · C++ · Firebase · HTML · CSS · JavaScript · Chart.js

### 03. Humanoid Robotics Simulation

**Domain:** Robotics · Simulation · Python

Exploring humanoid robot programming and simulation using Webots.

**Development objectives**

- Python-based robot controllers.
- Motor and joint control.
- Simulation-driven testing.
- Robot behavior development.
- A foundation for more advanced movement, perception, and autonomy.

**Technology stack:** Webots · Python · Robotics Control

### 04. Computer Vision — Hand Tracking Mouse

**Domain:** Computer Vision · Human–Computer Interaction

A real-time hand-tracking application that maps hand movements to computer mouse control.

**Key engineering features**

- Camera input and real-time image processing.
- Hand landmark tracking using MediaPipe.
- Screen-coordinate mapping.
- Cursor smoothing for more stable interaction.
- Gesture-based human–computer interaction.

**Technology stack:** Python · OpenCV · MediaPipe

### 05. ESP32-S3 Voice Assistant & Audio Processing

**Domain:** Embedded Systems · Digital Signal Processing · Audio Interfaces

An embedded audio project exploring voice interaction and audio processing using the ESP32-S3.

**Key engineering features**

- I²S digital microphone integration.
- Audio signal processing and frequency analysis.
- OLED-based visual feedback.
- Speaker output integration.
- Exploration of future voice-controlled intelligent devices.

**Technology stack:** ESP32-S3 · C++ · I²S · DSP · OLED
